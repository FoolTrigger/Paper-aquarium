# Модели рыб

В репозиторий уже включены **7 готовых 3D-моделей рыб с плавательной анимацией**, распространяемых по свободной лицензии **CC0 (Public Domain)** от Quaternius:

| Вид (`name`) | Название | Лист раскраски | Тип проекции | Размер в сцене |
|---|---|:---:|:---:|:---:|
| `percula` | Рыба-перкула (Clownfish) | ✅ есть | side (сбоку) | 1.4 |
| `goldfish2` | Золотая рыбка (Goldfish) | ✅ есть | side (сбоку) | 1.5 |
| `pufferfish` | Рыба-шар (Pufferfish) | ✅ есть | side (сбоку) | 1.6 |
| `mantaray` | Скат манта (Manta ray) | ✅ есть | top (сверху) | 2.4 |
| `reefshark` | Рифовая акула (Reef shark) | ✅ есть | side (сбоку) | 2.8 |
| `minkewhale` | Кит (Minke whale) | ✅ есть | side (сбоку) | 3.2 |
| `bottledolphin` | Дельфин (Bottlenose dolphin) | ✅ есть | side (сбоку) | 2.6 |

Все модели лежат в `assets/models/pack/<name>/<name>.glb`. Для каждой из них в `assets/coloring/` подготовлены векторные шаблоны раскрасок (`.svg`) с оптическими метками ArUco и единый PDF-альбом для печати на листе формата А4.

Благодаря встроенным CC0-моделям проект запускается и функционирует **сразу из коробки**, без необходимости покупать или конвертировать сторонние ассеты.

## Требования к 3D-моделям

- **Формат:** бинарный **`.glb`** (геометрия, риг и текстуры внутри одного файла).
- **Размер:** желательно до ~10–15 МБ на модель для быстрой загрузки на мобильных устройствах.
- **Состав:** одна рыба на файл, без постороннего окружения и камер.
- **Сжатие геометрии:** Draco поддерживается (декодер встроен в `vendor/draco/`).
- **Текстуры:** стандартные PNG/JPEG. Форматы сжатия KTX2/Basis не поддерживаются.
- **Ориентация:** любая. Движок (`assets/fish-frame.js`) автоматически вычисляет направление головы, спины и боков по геометрии или взмахам хвостового плавника.
- **Анимация:**
  - Если в файле присутствует скелет с клипом анимации — проигрывается первый клип с цикличным покачиванием.
  - Если скелета нет — процедурный шейдер (`addBend()`) плавно изгибает тело рыбы по синусоиде во время плавания.
- **Материалы и текстуры:** модель может использовать как свои встроенные текстуры (для «готовых рыбок из набора»), так и процедурную планарную развёртку для натягивания детского раскрашенного рисунка.

## Как добавить новый вид и сгенерировать раскраску

Каждый вид рыбы связан со своим листом раскраски через файл `assets/coloring/manifest.json`.

1. Положите файл `.glb` в `assets/models/pack/<name>/<name>.glb`.
2. Откройте в браузере `/tools/silhouettes.html`, дождитесь автоматической трассировки контура модели, нажмите «Скачать contours.json» и сохраните его в папку `tools/`.
3. В файле `tools/make-coloring.js` добавьте запись о новом виде в массив `SPECIES`:
   - имя папки (`name`),
   - название (`title`),
   - проекцию (`projection: 'side'` или `'top'`),
   - длину в единицах сцены (`len`).
4. Выполните генерацию шаблонов:
   ```bash
   node tools/make-coloring.js
   ```
   Скрипт автоматически рассчитает ArUco-метки, построит внешние и внутренние контуры плавников, обновит `manifest.json` и сгенерирует SVG-листы для всех поддерживаемых языков.
5. Пересоберите PDF-альбом:
   ```bash
   node tools/make-pdf.js
   ```
6. Проверьте распознавание через тестовый стенд `/tools/test-capture.html` (эмулирует различные углы наклона и освещенность).

## Подключение внешних коммерческих паков (например, CGTrader)

Если у вас есть коммерческий пак моделей в формате FBX (например, *Coral Reef Fish Collection*):
1. Распакуйте пак в папку `купил 3д рыбок/fbx/` (папка находится в `.gitignore`).
2. Запустите скрипт конвертации:
   ```powershell
   npm install --no-save fbx2gltf
   $env:FBX2GLTF = (Get-ChildItem node_modules -Recurse -Filter FBX2glTF.exe)[0].FullName
   powershell -ExecutionPolicy Bypass -File tools\convert-pack.ps1
   ```
3. Скрипт ужмет текстуры, оптимизирует прозрачность и сохранит готовые модели в `assets/models/pack/`.
