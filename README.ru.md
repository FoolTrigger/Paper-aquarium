# Аквариум с раскрасками

Домашняя игра для ребёнка по мотивам teamLab «Sketch Aquarium»: распечатал
лист, раскрасил фломастерами, сфотографировал телефоном — и рыбка поплыла
в аквариуме на большом экране.

```
раскраска A4  →  фото с телефона  →  текстура  →  3D-рыбка в сцене
```

Сервер на голом Node без единой зависимости, сцена на three.js, всё
хозяйство — папка `data/`.

## Ключевые возможности и технологии

- 💻 **Автономный установщик Windows и Portable ZIP (всё включено):** Готовый инсталлятор в один клик (`PaperAquarium-Setup.exe`) или портативный архив (`PaperAquarium-Portable.zip`) со встроенным рантаймом — не требуется устанавливать Node.js, git или использовать командную строку! Нативный лаунчер в трее Windows (`PaperAquarium.exe`), автозапуск браузера и бесконфликтный выбор портов.
- 📱 **Мгновенный вход с телефона по QR-коду:** прямо на главной странице (кнопка «С телефона») или по адресу `/qr` доступен QR-код локального адреса сервера в сети Wi-Fi. Достаточно навести камеру смартфона, чтобы моментально зайти в аквариум, фотографировать раскраски и кормить рыбок.
- 💾 **Надёжное сохранение данных при выходе:** Все созданные аквариумы, рисунки детей, клички рыбок, пользовательские фоны и параметры автоматически сохраняются при выключении программы. В установленной версии данные живут в `%APPDATA%\PaperAquarium\data` (не удаляются при обновлении программы), в портативной — в папке `./data`.
- 🎛️ **Раздельное отключение эффектов для ТВ и слабых устройств:** В меню аквариума добавлены независимые тумблеры украшательств (планктон, солнечные лучи God Rays, пузыри со дна, рельеф с кораллами и каустика воды), позволяющие получить плавные 60 FPS даже на бюджетных Smart TV, ТВ-приставках и старых телефонах.

- 🐟 **7 готовых бесплатных 3D-моделей (CC0):** клоун-перкула, золотая рыбка, рыба-шар, скат манта, рифовая акула, кит и дельфин уже включены в репозиторий вместе со скелетной анимацией плавания. Проект работает сразу после клонирования — ничего покупать или скачивать не требуется!
- 🎨 **Оптическое распознавание рисунков с WASM:** распознавание ArUco-меток по углам листа, исправление перспективы, вырезание контура и нормализация баланса белого ускорены на WebAssembly.
- 📱 **Оптимизация для бюджетных смартфонов:** адаптивный даунскейлинг при фотосъемке защищает от ошибок нехватки памяти (Out of Memory) и сбоев камеры даже на слабых устройствах. Поддерживается как живая камера, так и выбор готового фото из галереи.
- 🌊 **Графика нового поколения WebGPU + TSL с WebGL Fallback:** современный рендер WebGPU на шейдерах TSL (Three Shading Language) с процедурными каустиками воды и автоматическим переключением на WebGL на старых устройствах.
- 🪸 **Живой подводный мир:** объемные солнечные лучи (God Rays), частицы планктона, реалистичные струи пузырей со дна, рельефный ландшафт с кораллами, губками, камнями и водорослями.
- 🤖 **Поведение рыбок (Boids):** стайный интеллект, избегание столкновений со стеклом, естественные 3D-развороты и реакция на кормление.
- 🍞 **Интерактив:** рыбок можно кормить кнопкой «Покормить», давать им клички при отправке с телефона, выбирать процедурные шейдерные фоны или загружать свои картинки и видео-петли (.mp4 / .webm).
- 📺 **Быстрый запуск на ТВ:** 5-значный временный PIN-код позволяет за секунды подключить экран телевизора без набора ссылок пультом.
- 🔒 **Безопасность и мульти-аквариумы:** изолированные аквариумы по 10-значным криптографическим ссылкам, защита опасных действий паролем (соль + scrypt), защита от брутфорса и встроенные квоты против переполнения диска.
- 🌍 **2 языка (i18n):** интерфейс, раскраски, PDF-альбомы и правила доступны на русском и английском языках.
- 🛡️ **Приватность (GDPR):** сервер на чистом Node.js без единой внешней зависимости, ноль трекеров и сторонних cookies, автоочистка корзины через 30 дней.

## Быстрый старт (Windows)

### Вариант 1: Готовый релиз (Рекомендуется для пользователей)
Никаких настроек, установки Node.js или командной строки не требуется!

1. Перейдите в раздел **[Releases](../../releases)** на GitHub.
2. Скачайте удобный формат:
   - **`PaperAquarium-Setup.exe`** — полноценный установщик Windows. Устанавливает программу в систему, создаёт ярлыки на Рабочем столе и в меню Пуск.
   - **`PaperAquarium-Portable.zip`** — портативная версия. Распакуйте архив в любую папку (или на флешку) и запустите `PaperAquarium.exe`.
3. Запустите **`PaperAquarium.exe`**:
   - Приложение запустит локальный движок, откроет браузер по адресу `http://localhost:8000` и свернётся в системный трей Windows (возле часов).
   - Все параметры, добавленные рыбки и детские рисунки сохраняются автоматически и не пропадут при закрытии программы!

### Вариант 2: Запуск из исходного кода (Для разработчиков)

```bash
# Клонирование репозитория
git clone https://github.com/your-username/paper-aquarium.git
cd paper-aquarium

# Запуск сервера (требуется Node 18+, внешних зависимостей нет)
npm start
# или: node server.js
```

### Сборка установщика и релизов

Для сборки нативного лаунчера, Windows-установщика и портативного архива:

```powershell
# Запуск автоматических тестов
npm test

# Компиляция нативного лаунчера (PaperAquarium.exe через встроенный csc.exe)
npm run build:launcher

# Полная сборка релизов (Setup.exe через Inno Setup + Portable.zip)
npm run build:dist
```
Готовые файлы сохраняются в папку `dist/`.



## Как это работает

**Лист раскраски.** По углам четыре чёрные метки 6×6 клеток: 16 внутренних
клеток кодируют вид рыбы и номер угла. По ним съёмка находит лист на фото
и выправляет перспективу — метки закрашивать нельзя, всё остальное можно.
Контур рыбы напечатан тонкой серой линией, зоны плавников — бледным
пунктиром, чтобы их было видно, но чтобы ребёнок не принял подсказку за
часть рисунка.

**Съёмка.** `assets/capture.js` и WASM-модуль `assets/capture-wasm/`
ищут метки перебором порогов яркости, выправляют перспективу, вырезают
раскраску по контуру вида из манифеста и срезают полосу вдоль самой печатной
линии с субпиксельной дилатацией — иначе она осталась бы тёмной каймой.
Получается чистая текстура, которая натягивается на 3D-модель по планарной
развёртке бокового или верхнего силуэта. Для слабых телефонов предусмотрено
адаптивное сжатие кадра, исключающее нехватку оперативной памяти.

**Аквариум.** `demos/realistic-tank.html`: рыбы плавают в объёме, который
повторяет пирамиду обзора камеры, а не коробку — иначе у дальней стенки
они жались бы к центру экрана. Ориентацию модели (где нос, где спина)
сцена определяет сама по взмахам хвоста в анимации: `assets/fish-frame.js`.
На устройствах с поддержкой WebGPU включается TSL-конвейер с процедурными
каустиками, на остальных — надежный WebGL.

**Меню.** Клик в любом месте аквариума открывает меню: съёмка с камеры, готовые
рыбки из набора, кормление, печать раскрасок, выбор фона, удаление рыбок и «Открыть на
другом экране» — QR-код, прямая ссылка и пятизначный PIN для телевизора. Съёмка,
фон и раскраски открываются там же встроенной врезкой (`?embed=1`).

**Витрина.** Переменная `AQUA_DEMO_TANK` делает один аквариум публичной
витриной: главная показывает новичкам карточку «Посмотреть живой
аквариум», а ссылка с `?demo` открывает его с урезанным меню — покормить
и завести свой. Открытый по пину экран (`?tv`) меню сам не показывает:
им любуются, а управляют с телефона.

**Языки.** Русский и английский; при первом заходе берётся язык
устройства, дальше — тот, что выбрали переключателем. Все строки лежат
в `assets/i18n.js`, разметка размечена атрибутами `data-t`. Листы раскрасок
тоже двуязычные: подпись под рыбой печатается на языке страницы, а метки
в углах во всех версиях одинаковые — распознаётся любой лист.

## Запуск

```bash
node server.js          # http://localhost:8000
```

Нужен Node 18+. Ставить нечего: зависимостей нет, three.js лежит в `vendor/`.
Порт меняется переменной `PORT`.

Сервер печатает адреса всех сетевых интерфейсов — по ним аквариум
открывается с телефона и телевизора в той же Wi-Fi.

## Доступ

Аккаунтов нет. У каждого аквариума есть код из 10 знаков (он же адрес) и
пароль:

| | код (ссылка) | пароль |
|---|---|---|
| смотреть аквариум | ✅ | |
| добавить рыбку, покормить, сменить фон | ✅ | |
| удалить рыбок или аквариум, переименовать | | ✅ |

Съёмка и кормление нарочно без пароля: ребёнок открывает ссылку с телефона,
и требовать там пароль — значит убить всю затею. Испортить этим нечего,
необратимое закрыто.

Для телевизора есть короткая дорога: пункт «Открыть на другом экране»
в меню аквариума выдаёт временный код из пяти цифр (живёт 5 минут,
хранится в памяти сервера). Его вводят на главной в то же поле, что
и обычный код; перебор душится растущей паузой по адресу.

Код длинный не случайно: 31¹⁰ ≈ 8·10¹⁴ вариантов, перебором чужие рисунки
не найти. Пятизначный код (100 000 вариантов) перебирался бы за минуты.
От перебора пароля защищает пауза после пяти промахов, растущая до
десяти минут.

## Деплой

Всё для сервера лежит рядом: `Dockerfile`, `docker-compose.prod.yml`
и `.env.example`. Аквариум — один контейнер без своего прокси: HTTPS,
домен и сертификат берёт на себя Traefik через внешнюю сеть `web`.
Порядок, бэкапы и разбор частых поломок — в [DEPLOY.md](DEPLOY.md).

```bash
cp .env.example .env      # DOMAIN
docker compose -f docker-compose.prod.yml --env-file .env up -d --build
```

Базовые 7 моделей рыб (CC0) уже вшиты в Docker-образ. Дополнительный внешний пак можно примонтировать томом при необходимости.

## Что нужно знать перед тем, как выставлять наружу

- **Пароль ходит открытым текстом** в заголовке `X-Tank-Pass`. Внутри
  домашней сети это приемлемо, в интернете обязателен HTTPS — его берёт
  на себя прокси. На сервере от пароля хранится только scrypt-хеш с солью.
- **Добавление рыбок и загрузка фонов без пароля** — осознанное решение:
  ребёнок открывает съёмку по ссылке с телефона. Чтобы этим нельзя было
  забить диск, есть пределы (все меняются переменными окружения):

  | Переменная | По умолчанию | Что ограничивает |
  |---|---|---|
  | `AQUA_MAX_TANKS` | 200 | всего аквариумов на сервере |
  | `AQUA_TANKS_PER_HOUR` | 5 | новых аквариумов с одного адреса в час |
  | `AQUA_MAX_FISH` | 40 | рыбок в одном аквариуме |
  | `AQUA_MAX_BG` | 8 | своих фонов в одном аквариуме |
  | `AQUA_MAX_DATA_MB` | 2048 | размер всей папки `data/` |
  | `AQUA_DEMO_TANK` | — | код аквариума-витрины: главная показывает новичкам кнопку «Посмотреть живой аквариум» |

  Плюс жёсткие пределы на картинку: 3 МБ рыбка, 6 МБ фон, 12 МБ тело запроса.
- Сервер раздаёт только перечисленное в `staticFor()`: страницы, `assets/`,
  `vendor/`, `demos/`, `tools/` и из `data/` — лишь снимки сцен и свои фоны.
  Всё остальное, включая `.git` и сам `server.js`, отдаёт 404.

### Добавление дополнительных моделей (опционально)

Если вы хотите расширить набор видов или подключить сторонний пак моделей (например, купленный на CGTrader):

1. **Где искать:** Sketchfab (фильтр CC0/CC-BY, Animated), poly.pizza, Khronos glTF-Sample-Assets. Подробные требования к моделям описаны в [assets/models/README.md](assets/models/README.md).
2. **Конвертация внешнего пака FBX (для CGTrader):**
   ```powershell
   npm install --no-save fbx2gltf
   $env:FBX2GLTF = (Get-ChildItem node_modules -Recurse -Filter FBX2glTF.exe)[0].FullName
   powershell -ExecutionPolicy Bypass -File tools\convert-pack.ps1
   ```
3. **Генерация листа раскраски под новую рыбу:**
   - Открыть в браузере `/tools/silhouettes.html` для трассировки силуэта модели в `tools/contours.json`.
   - Добавить параметры рыбы в `SPECIES` внутри `tools/make-coloring.js`.
   - Запустить `node tools/make-coloring.js` и `node tools/make-pdf.js`.
System.Drawing). Любые свои `.glb`/`.gltf` кладутся в `assets/models/pack/`
руками — по папке на вид, и `pack.json` со списком рядом.

Виды в игре задаёт `assets/coloring/manifest.json`, а он собирается из
силуэтов моделей. Поэтому под другой набор рыб листы надо пересобрать:
`/tools/silhouettes.html` → `node tools/make-coloring.js`. Требования
к моделям, порядок добавления вида и грабли конвертации — в
[assets/models/README.md](assets/models/README.md).

## Инструменты

| Что | Где | Зачем |
|---|---|---|
| Силуэты | `/tools/silhouettes.html` | обводит модели пака, отдаёт `contours.json` и плавники поверх тела |
| Листы | `node tools/make-coloring.js` | собирает 12 листов A4 на трёх языках и манифест |
| PDF | `node tools/make-pdf.js` | печатает листы в `raskraski.<язык>.pdf` через headless Chrome; запускать после make-coloring |
| Проверка съёмки | `/tools/test-capture.html` | прогоняет каждый лист с перекосом, поворотом и шумом |
| Сборка пака | `tools/convert-pack.ps1` | FBX из купленного архива → glTF |

После правки листов проверка съёмки должна показывать «провалов нет»:
метки подбираются так, чтобы между кодами любых двух видов было не меньше
четырёх различающихся клеток.

## Данные

Всё живёт в `data/tanks/<код>/`: `meta.json` (имя, соль и хеш пароля),
`settings.json` (фон), `fish/` (рисунки и описания), `backgrounds/`
(свои фоны), `preview.jpg` (снимок для карточки). Удалённое переезжает
в `trash/` и `data/trash-tanks/`, а не стирается: внутри детские рисунки.

Удалённое лежит в корзине 30 дней (`AQUA_TRASH_DAYS`), потом стирается
безвозвратно: ребёнок стирает рисунок случайно, и вернуть его должно быть
можно, но вечная корзина на публичном сервере — это склад чужих детских
рисунков, которые люди считают удалёнными.

Папка `data/` в репозиторий не входит — это данные конкретной семьи.
Бэкап игры = копия этой папки.

Для публичного сервера рядом лежит страница [«Правила и данные»](terms.html)
